# Captured emoji metadata

These unchanged metadata snapshots were copied from the upstream-corpus conversion workspace to make the media mapping tools runnable from this private checkout.

- `official-emoji-labels.json`: captured official emoji labels used to identify native RuneScape Wiki file equivalents.
- `emojis_v2.json`: upstream emoji catalog, retaining its categories and asset IDs.

The mapping builders use these local snapshots rather than an absolute path on the original machine. They are metadata inputs, not replacement artwork or a new source-content sync.
