# Five long-guide previews

Five guides were selected randomly without replacement from the 20 current guides with at least 3,000 source words. Each live **Copy to wiki** button was clicked in Chrome, its complete output was pasted into RuneScape Wiki's native source editor, and **Show preview** was used. No page was saved.

| --- | ---: | ---: |
| Amascut 2000 Mechanics | 3,775 | 158/158 |
| Vorago — Tips And Tricks | 6,175 | 22/22 |
| Vorago Hm — Trio Hard Mode | 7,191 | 421/421 |
| Croesus | 3,100 | 62/62 |
| Yakamaru | 4,287 | 110/110 |

All source-text hashes matched. All 3,048 non-whitespace literal source nodes remained unchanged and in order. Image sequences matched the source; every image loaded with nonzero natural dimensions, including gear, presets and icons. Croesus's nine MP4 clips use original-player links because the destination cannot embed that host.

`five-long-preview-summary.json` is the compact result. Selection, detailed rendered evidence, literal checks and the read-only no-publication proof are in the adjacent JSON files. The `*-five-long-actual-copy.wiki` files preserve the exact captured button outputs. Screenshots show sampled rendered sections, including the Croesus preset and Yakamaru tank notes; they do not substitute for the full-page image and text checks.

Clipboard detail: Chrome's actual clipboard-write promises succeeded. Browser Use has a separate virtual clipboard, so the complete button output was read in chunks and transferred to that virtual clipboard before the native editor paste. This verifies the button output and destination rendering, without claiming automation read the operating-system clipboard.
