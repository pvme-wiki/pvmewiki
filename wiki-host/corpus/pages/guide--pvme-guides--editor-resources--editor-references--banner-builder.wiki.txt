[[PvME|PvME guide index]]

<span id="banner-builder"></span><p><nowiki>⬥ A banner summarising key information about a monster should be used atop every guide (or section, if there are multiple like an elite dungeon).</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ Please note, all banners are stored in the </nowiki>[https://docs.google.com/spreadsheets/d/1OGM9MBUG2bQVbHxlm86Xfs60soFcjINSOrPv1WL3Vgw/edit#gid=1657882095 <nowiki>PvME Spreadsheet</nowiki>]<nowiki>. Check here before creating one, and if you create one let us know in </nowiki>[https://discord.com/channels/534508796639182860/724129126314803230 <nowiki>Editors chat (external Discord)</nowiki>]<nowiki> so it can be added to the sheet.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ Head to </nowiki>[https://pvme.io/banner-builder/ <nowiki>https://pvme.io/banner-builder/</nowiki>]<nowiki> to start creating your first banner, in your browser, with no design knowledge required!</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ If you need help, however big or small please ask for help in </nowiki>[https://discord.com/channels/534508796639182860/724129126314803230 <nowiki>Editors chat (external Discord)</nowiki>]<nowiki>.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ Key information about banners:</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎• They are sized with the ratio 12w x 5h and a minimum of 300px in height</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎• They have the following components:</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎⬩ A blurry background representing the arena/area the monster lives in</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎⬩ The name picture of the monster</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎⬩ The monster's size (2x2, 5x5 etc)</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎⬩ Whether poison can be used</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎⬩ Which weapon the monster is vulnerable to</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎⬩ Whether familiar damage can be used</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><h2 id="instructions-for-manual-banner-creation"><ins><nowiki>Instructions for </nowiki><em><nowiki>manual</nowiki></em><nowiki> banner creation</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>⬥ In some situations (for example, the entire the entire internet falls to robots) you may need to create banners manually</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ Manual creation will work in any app that supports transparency, for example:</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎• Photoshop</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎• Gravit.io</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎• PowerPoint</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎• Paint.net</nowiki></p>
<nowiki>
</nowiki><h3 id="step-1-create-a-blurry-background-and-add-the-boxes"><nowiki>Step 1: Create a blurry background and add the boxes</nowiki></h3>
<nowiki>
</nowiki><ol><nowiki>
</nowiki><li><nowiki>Save </nowiki>[https://img.pvme.io/images/x5oFrjy7Kx.png <nowiki>this template file</nowiki>]<nowiki> to your machine and open it in your chosen editor</nowiki></li><nowiki>
</nowiki></ol>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎a. </nowiki><em><nowiki>Note: If using PowerPoint, unlock aspect ratio to fix pixel dimensions, then type the pixel value into the boxes that say &quot;cm/inch&quot; (e.g. &quot;1440px&quot;)</nowiki></em></p>
<nowiki>
</nowiki><ol><nowiki>
</nowiki><li><nowiki>In-game, visit the monster's area and use the Freecam or </nowiki>[https://runescape.wiki/w/Orb_of_oculus <nowiki>Orb of oculus</nowiki>]<nowiki> to find a nice backdrop for your banner</nowiki></li><nowiki>
</nowiki></ol>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎a. </nowiki><em><nowiki>Note: A darker environment </nowiki>[https://runescape.wiki/w/Skyboxes_and_filters <nowiki>skybox</nowiki>]<nowiki> will usually make the banner look cleaner - experiment!</nowiki></em></p>
<nowiki>
</nowiki><ol><nowiki>
</nowiki><li><nowiki>
</nowiki><p><nowiki>Screenshot the chosen area, and copy the image into your editor</nowiki></p>
<nowiki>
</nowiki></li><nowiki>
</nowiki><li><nowiki>
</nowiki><p><nowiki>Re-order your objects so the background is behind/under the template you started with</nowiki></p>
<nowiki>
</nowiki></li><nowiki>
</nowiki><li><nowiki>
</nowiki><p><nowiki>Crop the background image to the same size as the template</nowiki></p>
<nowiki>
</nowiki></li><nowiki>
</nowiki><li><nowiki>
</nowiki><p><nowiki>Add a strong blur effect to the background image so you can still see the general vibe of the area but not the details</nowiki></p>
<nowiki>
</nowiki></li><nowiki>
</nowiki></ol>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎a. </nowiki><em><nowiki>Note: If using PowerPoint, right-click image → Picture corrections → Sharpness (-70 to -90%)</nowiki></em></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><p><strong><nowiki>Good job! You should now have a banner that looks something like below:</nowiki></strong></p>
<nowiki>
</nowiki><p>[https://img.pvme.io/images/wMPYOsxghY.png <nowiki>Guide illustration</nowiki>]<nowiki>
​</nowiki></p>
<nowiki>
</nowiki><h3 id="step-2-add-the-monsters-name-and-image"><nowiki>Step 2: Add the monster's name and image</nowiki></h3>
<nowiki>
</nowiki><ol><nowiki>
</nowiki><li><nowiki>
</nowiki><p>[https://fonts.google.com/specimen/Russo+One <nowiki>Download the Russo One font</nowiki>]<nowiki> and install it to your machine</nowiki></p>
<nowiki>
</nowiki></li><nowiki>
</nowiki><li><nowiki>
</nowiki><p><nowiki>Open and copy </nowiki>[https://img.pvme.io/images/av8OFsrGoq.png <nowiki>this guide layer</nowiki>]<nowiki> into your editor</nowiki></p>
<nowiki>
</nowiki></li><nowiki>
</nowiki><li><nowiki>
</nowiki><p><nowiki>Staying within the red lines, add a text box (start with font size 102px) and enter the boss' name</nowiki></p>
<nowiki>
</nowiki></li><nowiki>
</nowiki></ol>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎a. </nowiki><em><nowiki>Note: If the monster has a long name, reducing the font-size is okay as long as it stays within the red lines</nowiki></em></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎b. </nowiki><em><nowiki>Note: If using PowerPoint, you will need to eyeball the font-size rather than use pixel font-sizes</nowiki></em></p>
<nowiki>
</nowiki><ol><nowiki>
</nowiki><li><nowiki>
</nowiki><p><nowiki>Centre the boss' name horizontally in the middle of the white boxes (it should be off-centre to the left)</nowiki></p>
<nowiki>
</nowiki></li><nowiki>
</nowiki><li><nowiki>
</nowiki><p><nowiki>Get the image of the monster from the Runescape Wiki:</nowiki></p>
<nowiki>
</nowiki></li><nowiki>
</nowiki></ol>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎a. Open the Runescape Wiki, navigate to the monster's page</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎b. Click on the main image - it should maximise the image file</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎c. Right-click download this image</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎d. Import it into your editor (note: this is an important step in some editors, as copying sometimes loses the transparent background)</nowiki></p>
<nowiki>
</nowiki><ol><nowiki>
</nowiki><li><nowiki>
</nowiki><p><nowiki>Move the monster's image to the empty space on the right, and resize as appropriate</nowiki></p>
<nowiki>
</nowiki></li><nowiki>
</nowiki><li><nowiki>
</nowiki><p><nowiki>You can now safely hide or delete the red guide layer</nowiki></p>
<nowiki>
</nowiki></li><nowiki>
</nowiki></ol>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><p><strong><nowiki>Good job! You should now have a banner that looks something like below:</nowiki></strong></p>
<nowiki>
</nowiki><p>[https://img.pvme.io/images/4DdX0AEOHn.png <nowiki>Guide illustration</nowiki>]<nowiki>
​</nowiki></p>
<nowiki>
</nowiki><h3 id="step-3-add-the-summary-boxes"><nowiki>Step 3: Add the summary boxes</nowiki></h3>
<nowiki>
</nowiki><ol><nowiki>
</nowiki><li><nowiki>Now comes the fiddly part! Copy in the relevant icons from the below list to the remaining white boxes, </nowiki><ins><nowiki>ensuring they are centred within their box</nowiki></ins><nowiki>.</nowiki></li><nowiki>
</nowiki></ol>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎‎ ‎ ‎ ‎ ‎‎a. </nowiki><em><nowiki>Note: The only non-icon box is the bottom-left, where you will need to use the same font as before to type in the boss' size (start with font size 53px)</nowiki></em></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎‎ ‎ ‎ ‎ ‎‎b. </nowiki><em><nowiki>Note: You should be able find the boss' size in a table on the </nowiki>[https://runescape.wiki/w/Seren_godbow#Recommended_bosses <nowiki>Seren godbow Wiki page</nowiki>]</em></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎‎ ‎ ‎ ‎ ‎‎c. </nowiki><em><nowiki>Note: If using PowerPoint, the align tools are under &quot;Arrange&quot;</nowiki></em></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
