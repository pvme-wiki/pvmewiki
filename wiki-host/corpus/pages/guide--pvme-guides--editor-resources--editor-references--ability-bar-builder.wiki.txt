[[PvME|PvME guide index]]

<h2 id="introduction"><ins><nowiki>Introduction</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>⬥ Some guides require sharing an action bar to go alongside them, but it can be difficult to make in-game if you don't have spare action bars, or if you don't have the required abilities to do so unlocked.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ A couple of tools have been developed that make this process easier.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><h2 id="ability-bar-builder"><ins><nowiki>Ability Bar Builder</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>⬥ Try it here: </nowiki><strong>[https://pvme.github.io/ability-bar-builder/ <nowiki>https://pvme.github.io/ability-bar-builder/</nowiki>]</strong></p>
<nowiki>
</nowiki><p>[https://img.pvme.io/images/H3MDTbTKzK.png <nowiki>Guide illustration</nowiki>]<nowiki>
⬥ This tool (created by Contributor name unavailable) allows you to quickly create custom revolution bars that you can then take screenshots of, or directly export as </nowiki><code><nowiki>.png</nowiki></code><nowiki>.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎• You can then send it to </nowiki>[https://discord.com/channels/534508796639182860/771436827214086154 <nowiki>Guide media upload and request (external Discord)</nowiki>]<nowiki> to get a image link to use in guides generated.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ To use it, </nowiki><strong><nowiki>simply click on an ability bar slot and choose an ability to go there</nowiki></strong><nowiki>.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ You can use the toggles above to change the bar length, toggle the yellow outline on/off, and remove the white number icons.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><h2 id="revo-bar-tool"><ins><nowiki>Revo Bar Tool</nowiki></ins></h2>
<nowiki>
</nowiki><p><strong><nowiki>Note</nowiki></strong><nowiki>: This tool may sometimes be down (towards the end of a month), due to excessive traffic.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ Try it here: </nowiki><strong>[https://revocalc.fly.dev/ <nowiki>https://revocalc.fly.dev/</nowiki>]</strong></p>
<nowiki>
</nowiki><p>[https://img.pvme.io/images/50aZhme.png <nowiki>Guide illustration</nowiki>]<nowiki>
⬥ This tool was created by Contributor name unavailable and allows you to create custom revolution bars, similar to the </nowiki><strong><nowiki>Ability Bar Builder.</nowiki></strong></p>
<nowiki>
</nowiki><p><nowiki>⬥ To use it, </nowiki><strong><nowiki>drag and drop abilities from the menus above into the bar</nowiki></strong><nowiki>. To clear a slot on the bar, simply drag out the ability from it.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ You can also simulate using the revolution bar in combat, to compare its long-term sustained DPS with other bars.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
