[[PvME|PvME guide index]]

<h2 id="introduction"><ins><nowiki>Introduction</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>⬥ Try it for yourself: </nowiki><strong>[https://pvme.github.io/guide-editor/ <nowiki>https://pvme.github.io/guide-editor/</nowiki>]</strong></p>
<nowiki>
</nowiki><p><nowiki>⬥ The </nowiki><strong><nowiki>PvME Guide Editor</nowiki></strong><nowiki>, developed by @pleb0025, is a comprehensive editor tool to accelerate guide making for PvME.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ It is the recommended way to write guides, as it makes it easier to check them with the live preview, and prevent issues from occurring with the help of the integrated error checker.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ Additionally, the </nowiki><code><nowiki>/files</nowiki></code><nowiki> ‎bot command offers the ability to open any current guide directly in the guide editor.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><h2 id="editor-layout"><ins><nowiki>Editor Layout</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>⬥ When you open the website you'll see the a layout similar to the following.</nowiki></p>
<nowiki>
</nowiki><p>[https://img.pvme.io/images/zr62id2.png <nowiki>Guide illustration</nowiki>]<nowiki>
⬥ </nowiki><strong><nowiki>Input Text</nowiki></strong><nowiki> is where your input text goes.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ </nowiki><strong><nowiki>Discord Preview</nowiki></strong><nowiki> is a live preview of what it will look like in discord.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ </nowiki><strong><nowiki>Error Checker</nowiki></strong><nowiki> displays any formatting and syntax errors in your text that need to be corrected.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ The </nowiki><strong><nowiki>Formatting Bar</nowiki></strong><nowiki> contains tools to help you format your input text.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎• Covered in detail below.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>

</nowiki><h2 id="formatting-bar"><ins><nowiki>Formatting Bar</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>⬥ The formatting bar at the top contains tools to help format your input text.</nowiki></p>
<nowiki>
</nowiki><h3 id="text-formatting"><nowiki>Text Formatting</nowiki></h3>
<nowiki>
</nowiki><p>[https://img.pvme.io/images/WcekSyf.png <nowiki>Guide illustration</nowiki>]<nowiki>
⬥ </nowiki><strong><nowiki>B</nowiki></strong><nowiki> </nowiki><em><nowiki>I</nowiki></em><nowiki> </nowiki><ins><nowiki>U</nowiki></ins><nowiki> </nowiki><del><nowiki>S</nowiki></del><nowiki> - </nowiki><strong><nowiki>Bold</nowiki></strong><nowiki>, </nowiki><em><nowiki>italicize</nowiki></em><nowiki>, </nowiki><ins><nowiki>underline</nowiki></ins><nowiki>, and </nowiki><del><nowiki>strike through</nowiki></del><nowiki>.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ </nowiki><strong><nowiki>H1</nowiki></strong><nowiki> - Indents, bolds and underlines paragraph.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ </nowiki><strong><nowiki>H2</nowiki></strong><nowiki> - Bolds and underlines paragraph.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>

</nowiki><h3 id="lists-and-code"><nowiki>Lists and Code</nowiki></h3>
<nowiki>

<nowiki>
</nowiki><p><nowiki>⬥ </nowiki><strong><nowiki>2 buttons on the right</nowiki></strong><nowiki> - Reformat selected text as </nowiki><strong><nowiki>inline code</nowiki></strong><nowiki> and as a </nowiki><strong><nowiki>code block</nowiki></strong><nowiki> respectively.</nowiki></p>

</nowiki><h3 id="misc-buttons"><nowiki>Misc. Buttons</nowiki></h3>

</nowiki><h2 id="input-text"><ins><nowiki>Input Text</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>⬥ Use the </nowiki><strong><nowiki>left box for input text</nowiki></strong><nowiki> to write the raw content for your guides.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ There is a </nowiki><strong><nowiki>live preview on the right</nowiki></strong><nowiki>, as shown in the layout image above.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ See the question mark </nowiki><strong><nowiki>?</nowiki></strong><nowiki> button on the top right of the web editor for tips to make editing a little quicker.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><h2 id="error-checker"><ins><nowiki>Error Checker</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>⬥ If any style or formatting errors are present in your guide, then they will be listed here.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ The checker is the same as the one used during pull requests on GitHub, so </nowiki><strong><nowiki>if you see any errors here, fix them before submitting it!</nowiki></strong></p>
