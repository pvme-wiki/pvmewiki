<h2 id="introduction"><ins><nowiki>Introduction</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>⬥ The </nowiki><strong><nowiki>Rotation Builder</nowiki></strong><nowiki> is a tool that was developed by @pleb0025 to make writing rotations for guides easier.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ Try it for yourself here: </nowiki><strong>[https://pvme.github.io/rotation-builder/ <nowiki>https://pvme.github.io/rotation-builder/</nowiki>]</strong></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><h2 id="rotation-builder-layout"><ins><nowiki>Rotation Builder Layout</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>⬥ When you open the website you'll see the a layout similar to the following.</nowiki></p>
<nowiki>
</nowiki><p>[https://img.pvme.io/images/bigtPP9.png <nowiki>Guide illustration</nowiki>]<nowiki>
⬥ </nowiki><strong><nowiki>Input Text</nowiki></strong><nowiki> is where your input text goes.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ </nowiki><strong><nowiki>Output</nowiki></strong><nowiki> is a live output of the emojis from your input text.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ </nowiki><strong><nowiki>Copy Options</nowiki></strong><nowiki> allow you to copy the text in a couple different output options.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎• </nowiki><strong><nowiki>Copy Discord</nowiki></strong><nowiki> copies the text as it would be input for a guide in PvME.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎• </nowiki><strong><nowiki>Copy Draw.io</nowiki></strong><nowiki> copies the raw HTML for import into </nowiki><strong><nowiki>draw.io</nowiki></strong><nowiki> (a free online tool that helps make flowcharts, diagrams, etc.)</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><h2 id="input-text"><ins><nowiki>Input Text</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>⬥ When typing the name or alias of an emoji from </nowiki>[https://pvme.io/pvme-settings/#emojis <nowiki>https://pvme.io/pvme-settings/#emojis</nowiki>]<nowiki>, the website will automatically display it as an emoji instead of text.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ For example, typing the raw input text </nowiki><code><nowiki>gbarge → assault → deci → destroy</nowiki></code><nowiki> ‎will yield the following output:</nowiki></p>
<nowiki>
</nowiki><p>[https://img.pvme.io/images/7x5KPtM.png <nowiki>Guide illustration</nowiki>]<nowiki>
⬥ More examples of how to format input are given on the website.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><h2 id="saving-output"><ins><nowiki>Saving Output</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>⬥ </nowiki><strong><nowiki>To save it as an image</nowiki></strong><nowiki>: please screenshot </nowiki><em><nowiki>only</nowiki></em><nowiki> the output section.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎• A picture of the rotation looks cleaner and is more easily shared with people than a ton of emoji text IDs.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ </nowiki><strong><nowiki>To use emojis directly in a guide</nowiki></strong><nowiki>: use the </nowiki><strong><nowiki>Copy Discord</nowiki></strong><nowiki> button and paste the copied text into your guide.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ Copying the data for draw.io: follow the tutorial given at the bottom of the website.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
