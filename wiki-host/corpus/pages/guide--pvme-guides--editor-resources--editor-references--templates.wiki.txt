<span id="templates-tips-for-writing-guides"></span><p><nowiki>This guide showcases many of the ways you can be more efficient when writing guides, whether that be through copy-able templates, code snippets or other tips.</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><p><strong><nowiki>It assumes you are using the </nowiki>[https://pvme.github.io/guide-editor/ <nowiki>PvME Guide Editor</nowiki>]<nowiki> to write &amp; live preview your guides.</nowiki></strong></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><h2 id="finding-and-using-templates"><ins><nowiki>Finding and using Templates</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>In the Guide Editor toolbar you will see a &quot;Template&quot; dropdown, containing starting points for our main guide types:</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ Boss Guide</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ AFK Guide</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ Slayer Guide</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ Command Embed</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><p><nowiki>Simply click &quot;copy&quot; and paste these into the editor to get started on your guide, as in the screenshot below:</nowiki></p>
<nowiki>
</nowiki><p>[https://img.pvme.io/images/ArqoW60TuE.png <nowiki>Guide illustration</nowiki>]<nowiki>
​</nowiki></p>
<nowiki>
</nowiki><h2 id="finding-emojis"><ins><nowiki>Finding emojis</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>There are two ways to find an emoji:</nowiki></p>
<nowiki>
</nowiki><ol><nowiki>
</nowiki><li><nowiki>
</nowiki><p><nowiki>In the Guide Editor, simply start typing </nowiki><code><nowiki>:emojiname</nowiki></code><nowiki> ‎and it will bring up a list - select the one you want</nowiki></p>
<nowiki>
</nowiki></li><nowiki>
</nowiki><li><nowiki>
</nowiki><p><nowiki>Search the full repository of emojis at </nowiki>[https://pvme.io/pvme-settings/#emojis <nowiki>https://pvme.io/pvme-settings/#emojis</nowiki>]</p>
<nowiki>
</nowiki></li><nowiki>
</nowiki></ol>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><h2 id="linking-items-to-the-wiki"><ins><nowiki>Linking items to the Wiki</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>Many of our guides link items and gear to the </nowiki>[https://runescape.wiki/ <nowiki>RS Wiki</nowiki>]<nowiki>. Follow these steps:</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ Use the pattern: </nowiki><code><nowiki>[Item name](&lt;http://runescape.wiki/w/Item_name&gt;) &lt;:emoji:&gt;</nowiki></code><nowiki>​</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎• Wrap the URL in </nowiki><code><nowiki>&lt;&gt;</nowiki></code><nowiki> ‎to prevent it showing a preview</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎• Most items only capitalise the first word</nowiki></p>
<nowiki>
</nowiki><p><nowiki>‎ ‎ ‎ ‎• Replace spaces with underscores</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ Test your URL in the guide editor by clicking on it</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><p><nowiki>See the following example:</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki><code><nowiki>[Channeller's ring](&lt;http://runescape.wiki/w/Channeller's_ring&gt;) &lt;:channellersring:839903943404027914&gt;</nowiki></code><nowiki>​</nowiki></p>
<nowiki>
</nowiki><p><nowiki>→ </nowiki>[http://runescape.wiki/w/Channeller's_ring <nowiki>Channeller's ring</nowiki>]<nowiki> </nowiki>[https://cdn.discordapp.com/emojis/839903943404027914.png?v=1 <nowiki>channellersring</nowiki>]</p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><h2 id="using-embeds"><ins><nowiki>Using Embeds</nowiki></ins></h2>
<nowiki>
</nowiki><p><nowiki>Sometimes we use a special Discord &quot;embed&quot; to format messages in a pretty way - these are written in JSON. When inside a JSON, common punctuation like bullets or new lines will not work as normal; use the following to achieve what you are looking for:</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ </nowiki><strong><code><nowiki>\n</nowiki></code></strong><nowiki> → adds a new line</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ </nowiki><strong><code><nowiki>\u00a0\u00a0\u00a0\u00a0</nowiki></code></strong><nowiki> = adds a new line + 4 spaces</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ </nowiki><strong><code><nowiki>\n⬥</nowiki></code></strong><nowiki> → adds a new line + a bullet</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ </nowiki><strong><code><nowiki>\n\u00a0\u00a0\u00a0\u00a0•</nowiki></code></strong><nowiki> → adds a new line + 4 spaces + a sub-bullet</nowiki></p>
<nowiki>
</nowiki><p><nowiki>⬥ </nowiki><strong><code><nowiki>\n\u200B</nowiki></code></strong><nowiki> → adds a blank line</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><p><nowiki>A example embed can be seen below:</nowiki></p>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
<nowiki>
</nowiki><pre>..
{
  &quot;embed&quot;: {
    &quot;title&quot;: &quot;__[embed title]__&quot;,
    &quot;description&quot;: &quot;[embed description]\n\u200B&quot;,
    &quot;color&quot;: 39423,
    &quot;fields&quot;: [
      {
        &quot;name&quot;: &quot;__[field 1 name]__&quot;,
        &quot;value&quot;: &quot;[field 1 contents]&quot;
      },
      {
        &quot;name&quot;: &quot;__[field 2 name]__&quot;,
        &quot;value&quot;: &quot;⬥ Field 2 contents\n⬥ Field 2 contents&quot;
      }
    ]
  }
}
..embed:json
</pre>
<nowiki>
</nowiki><p><nowiki>​</nowiki></p>
