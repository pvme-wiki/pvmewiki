# PvmePresentation

This MediaWiki 1.43 extension loads scoped ResourceLoader styles for mainspace `PvME` and `PvME/...` titles. Ordinary guide views add navigation and a disposable visual reader outside `#mw-content-text`. Explicit source lists become cards; voice cues become tables. Original article text, link targets and ordering remain unchanged; classes, data attributes and accessibility labels enhance its DOM. A toggle retains the native wiki view. On editor activation or any source-content replacement, the visual reader retires until reload so it cannot hide a newly saved revision. No images or fonts are bundled; light reader panels preserve contrast under Vector's surrounding day/night theme.

The two Dagannoth Kings preset grids contain factual item labels, exact source positions and item-specific qualifications captured from the guide's linked public presets. They are dated references, not inferred requirements or new guide revisions. Preset tiles reflow on phones with their source row/column labels retained. Unsupported action-bar imagery stays an explicit source reference until ability identities/order or reuse scope can be established.

`Copy for RuneScape Wiki` performs a read-only same-origin revision GET when clicked. It converts the complete latest published wikitext, including community edits, with its exact revision permalink, timestamp, attribution and source history. It does not send edits, open the official wiki, fetch a pinned replacement, or copy only a selected excerpt. Native headings, contiguous lists and tables replace HTML layout. Verified factual icon names become official-wiki links; other guides use upstream external links rather than assumed ported titles. Templates, comments, unsupported markup and nonstandard list numbering stop the export rather than copy a partial result. Clipboard success/failure is announced; a full readonly selectable export is available after conversion even when clipboard access fails.

Presentation is enabled by default; `MW_PRESENTATION_ENABLED=false` opts out on restart. Deploying the previous source revision also rolls back presentation. Neither path changes the immutable seed XML, import marker, database or page revisions. The candidate migration scripts are separate, and their network apply path is disabled.

On ordinary article views, the visible H1 shows the final segment of a `PvME/...` title. The canonical page title, URL, and browser tab title remain unchanged; the converter's breadcrumbs keep the parent path visible in the article. The `PvME` hub retains its H1.

The separate staged converter can use ordinary MediaWiki-safe `<div>` and `<span>` elements with semantic classes for headings, callouts, phases, tables, rotations and indexes. Those authored page candidates are not applied by this extension. CSS pseudo-elements expose factual fallback labels from attributes; duplicate icon labels beside an existing item link are hidden only in the disposable visual reader. The original view and exported current revision remain available.

Suggested markup uses native headings, lists, links, and tables inside the classed containers. A media fallback should name the unavailable asset or guide reference in text and link to an allowed source when appropriate. The portrait and icon selectors support only locally approved assets if one is later supplied; no assets are bundled here.
