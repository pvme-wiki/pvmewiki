Intro to Editing Continued

Now that you are more familiar with the most basic and essential tools used for editing, this channel will outline the other tools commonly used in creating new guides from start to finish.

​

Essential Tools

These are tools that are used in almost every guide:

Note: Tutorials for all tools can be found in their respective forums in #editor-resources

⬥ Guide Editor - Has all text formatting tools built in, as well as the style guide rule set integrated.

⬥ Style Guide - Has all of our formatting rules explained in great detail. This is built into the Guide Editor and will display any broken styling rules in the bottom-left window of the Guide Editor website.

‎‎ ‎ ‎ ‎• Example: https://img.pvme.io/images/hKXqQoi3fs.png

‎‎ ‎ ‎ ‎ ‎ ‎ ‎ ‎⬩ There was an empty space after the last word on line 12, so the Guide Editor informed me to delete it.

⬥ Templates - Has the skeleton structure for various guides/embeds pre-made so you can just copy paste and fill in blanks as needed to give you a head start on guide creation. This channel also has information on how to format text within embeds.

‎ ‎ ‎ ‎• Note: There are tools built into the Guide Editor that offer the same functionality

⬥ Preset Maker - Used to provide a standardized UI so the layout looks the same across all guides.

‎ ‎ ‎ ‎• Click an inventory slot and type the name of an item to see it populate the slot.

⬥ Ability Bar Builder - Used for creating Revolution bars for AFK and Slayer guides.

‎ ‎ ‎ ‎• Click a slot on the bar and select an ability from the popup.

⬥ Rotation Builder - Has built-in autoformatting tools to turn common ability names into emoji code output which you can copy/paste into the guide editor.

‎ ‎ ‎ ‎• Example: gbarge automatically becomes when typed into the rotation builder.

Niche Tools

These are the extra tools that editors can use to make their guides more pretty and refined:

Note: Tutorials for all tools can be found in their respective forums in #editor-resources. If you are not comfortable using these tools, do your best to explain what is needed in #editors-chat and ask someone else to make them for you to add to the guide later.

⬥ Tile Map Generator - Used for making map pictures with gridlines on them to mark exact tiles to place cannons/player standing spots/boss spawn locations.

⬥ Banner Builder - Used for creating banners for every boss guide that describes their size and susceptibilities to things like poison or familiar damage.

⬥ Hyperlinked Emojis - A raw document of emoji codes that link the emoji item to the appropriate wiki page for the item.

‎ ‎ ‎ ‎• Example: Opening the website and using ctrl + F ‎to search for Ascension Crossbow ‎will show you a line that has this text: [Ascension crossbow](<https://runescape.wiki/w/Ascension_crossbow>) <:ascmh:513190158468775936>. If you copy paste that whole line and post it into the Guide Editor, it will display as Ascension crossbow .

⬥ Emoji Combinations - A channel with content similar to Hyperlinked Emojis. It has quick access copy paste text for common combinations of emojis such as <:graspingpouchblack:1390439136875253810> <:bloodrune:536252658970001409> <:astralrune:536252658961481769> <:bodyrune:536252659301089280> <:soulrune:536252660333019136>, which will display in the Guide Editor as .

⬥ Forum Icon Builder - Used for creating icons for our Discord forums.

Making a Guide From Start to Finish

Here's a quick overview of the steps taken to make guides from scratch:

  1. Open the Guide Editor.

  2. Click Templates.

  3. Select the guide you want to make. For this, I'll choose a standard guide.

  4. Create a banner for the boss using the Banner Builder, or ask someone in #editors-chat to create one for you.

‎ ‎ ‎ ‎a. These are archived in the PvME Spreadsheet in the Art Resources ‎tab.

  1. Intro: Describe the boss where the template requests the info.

  2. Presets and Relics: Use the Preset Maker, or post your preset from in-game, describe the relics/niche items used, and ask someone in #editors-chat to create the preset for you.

  3. Mechanics: Describe the mechanics where the template requests the info.

  4. The Fight: Describe an overview of the fight where the template requests the info.

  5. Rotations: Utilise the Rotation Builder to get your rotations written down quickly, then hit the copy discord ‎button. Then paste that copied output into this section of the guide editor.

  6. Example Kills: Put a couple youtube video links showcasing quality kills here

  7. Table of Contents: Click the Table of Contents ‎dropdown button and select Categorized. Click Copy, then paste that copied output at the bottom of the guide.

  8. Click Export to .txt file ‎and paste the copied output into #suggestions which will upload as a file. Describe your guide in the suggestion and ask that someone uploads it to GitHub for you.
