# PvME wiki work

Guide content is verbatim source material. Every source word, its order, gear note, rotation, caption, warning, link and visual must survive unchanged. The user's requirement is an additive presentation layer only: do not rewrite, summarise, substitute, omit or reorder guide information. Formatting, navigation and source-backed visual grouping may augment the original. Check exact text and media coverage before publishing.

For new shared interface labels only, apply [.agents/skills/pvme-interface-copy/SKILL.md](.agents/skills/pvme-interface-copy/SKILL.md). Its editorial guidance does not authorize changing source guide wording. Review actual rendered copy before publishing.

Keep existing imported source and community revisions intact. Make presentation changes in the shared module and publish editorial rewrites as editable wiki content with attribution. No generated artwork. Code-drawn SVG primitives are allowed. Do not add or run tests for formatting or copy passes.
