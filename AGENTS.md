# PvME wiki work

For every new or revised guide, template and shared interface, read and apply [.agents/skills/pvme-interface-copy/SKILL.md](.agents/skills/pvme-interface-copy/SKILL.md). Treat clear, natural player instructions as a release requirement alongside gameplay accuracy. Preserve source credits, exact cues and mechanics. Review actual rendered copy before publishing.

Keep existing imported source and community revisions intact. Make presentation changes in the shared module and publish editorial rewrites as editable wiki content with attribution. No generated artwork. Code-drawn SVG primitives are allowed. Do not add or run tests for formatting or copy passes.
